Gang of four suggested 23 design pattern
Creational Design Pattern:Abstract factory, Builder, Factory method, Prototype and Singleton
Structural Design Pattern:Adapter, Bridge, Composite, Decorator, Facade, Flyweight and Proxy
Behavioral Design Pattern:Chain of Responsibility, Command, Interpreter, Iterator, Mediator, Memento, Observer, State, Strategy, Template method, Visitor
Ambion Design Pattern
DESIGN PATTERN OVERVIEW:represents all the best practices used by experienced object-oriented software developers.Design patterns are solutions to general problems that software developers face during software development.
Characteristics:Smart: Elegant solution that a novice would not think of immediately.
Generic: Normally not dependent on a specific software system, any programming language or application domain. They are generic in nature.
Well-proven: They have been identified from a real, OO system. They are not results or simple paper work, but they have been successfully tested in several systems.
Simple: They are usually quite small, involving a small number of classes. The complex systems are built using different design patterns and their combinations.
Reusable: they are documented in  such a manner to increase reusability.
Object Oriented: They are built with the basic OOp mechanisms such as classes, objects, generalization and polymorphism.


Gang OF FOUR:In 1994, four C++ developers published a book Design Pattern-Elements of Reusable Object-Oriented Software which includes 23 design patterns.According to them, design patterns are based on the following principles of object oriented design.1. Program to an interface not an implementation2. Favor object composition over inheritance

Drawbacks of Design Patterns:

Many developers are not willing to accept the work of others
