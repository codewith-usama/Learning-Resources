Maven Architecture
Ruquirment for build
Source Code(Present in workspace)
Compiler (Remote repo->local repo->workspace)
Dependencies (Remote repo->local repo->workspace)

First it get Source code from gitHub repo, then we define the dependencies in pom.xml and commands goals. After this it will ask to fetch dependency from .M2 local repo in pc if found return it otherwise ask from remote/central repo for that particular repo and after this it will also creates a local repo in .M2

Local repo: refers to the machine of developer
Remote repo: refer to the repo present on a webserver which is used when Maven in needs. first it will download in local repo than come in pom.xml
Central repo: refers to the Maven community that comes into action when there is a need of dependencies and these dependencies cannot be found in the local repo

Maven lifecycle:
1. Generate Resoource (Dependencies)
2. Compile Code
3. Unit test
4. Package (Build)
5. Install (into local repo & artifactory)
6. Deploy (to servers)
7. clean (delete all run tome file) eg mvn install, mvn cleean package
